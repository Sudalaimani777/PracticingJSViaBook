JavaScript :-
    Dynamic Programming Language.
    Specially for Web Development.
    Make the website more interactive.

    HTML is the noun, CSS is the adjective (description) and JavaScript is the verb (action.)

Writing the JavaScript :-
    js console.
    Text Editor - VS Code (IDE).
    Online Playground -CodePen,CodeSandBox
    
DOM :-
    document -> document of the webpage
    document.body -> Document of the body
    document.body.children -> Return the group of Elements. (div, p, article) All the Elements within the body.
    document.getElementById("header"); -> Accessing the Element using the Id attribute.
    document.querySelector("wrapper"); -> Selecting the Element
    document.querySelectorAll(".wrapper"); -> Selecting the All Element
    document.getElementByTagName("h1"); -> Selecting the Element by using the TagName

    document.title = "Hello"; -> Change the title of the webpage.
